# AquaSense

### Indigenous Leak Detection Sensor System for Water Supply Pipelines

AquaSense is an IoT-based hardware and web platform designed to detect, locate, and monitor water pipeline leakages in real time.

The system aims to reduce water wastage, non-revenue water, maintenance costs, and delays in identifying pipeline failures.

## Problem

Undetected leaks in water distribution networks can result in:

* Significant water wastage
* Increased operational and maintenance costs
* Reduced water supply efficiency
* Delayed detection of pipeline failures

Existing leak detection solutions can be expensive and difficult to deploy, particularly in rural and small-town water supply systems.

## Solution

AquaSense combines pipeline sensors, a microcontroller, IoT communication, and a web-based monitoring dashboard to provide continuous pipeline monitoring.

The system can:

* Detect pipeline leakages
* Estimate the location of a leakage
* Monitor pipeline parameters in real time
* Generate alerts for abnormal conditions
* Store and analyze historical sensor data
* Support remote monitoring and maintenance

## Hardware

The prototype may include:

* Pressure Sensor
* Flow Sensor
* Acoustic/Vibration Sensor
* Microcontroller
* Communication Module
* GPS/GNSS Module
* Battery/Power Supply

## Web Dashboard

The AquaSense website provides:

* Real-time sensor readings
* Pipeline status
* Leak alerts
* Sensor locations
* Historical data
* Maintenance information

## Technology Stack

**Hardware:** Microcontroller, Sensors, IoT Communication

**Frontend:** React, HTML, CSS, JavaScript

**Backend:** Node.js, Express.js

**Database:** MongoDB / Firebase

**Communication:** LoRa / Wi-Fi / GSM / NB-IoT
